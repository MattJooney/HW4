HW 4 Blog

For this assignment, I decided to go with extending on Pitch Set Theory using transpose, inverse, and retrograde implementations. More specifically, I tried using pitch set theory to create a melody generator using numbers generated in an unpredictable manner.

First, I used an array of integers from 0–11 in order to implement the 12-tone chromatic scale (C=0, C#=1, D=2, D#=3, and so on). In order to apply transposition, I assigned n to be semitones and p to be pitch with p = (p + n) % 12 to determine the final pitch after n semitones transposition. The modulo 12 is to keep the integer within the 0–11 range in case the transposition goes further than an octave. Therefore, transposing a C major chord (0, 4, 7) by five semitones gives an F major chord (5, 7, 0).

With inversion, I used p = (12 - p) % 12 as my formula, which inverses the pitch so that the beginning pitch and resulting pitch add up to 12. 0 stays 0, 1 becomes 11, 2 becomes 10, and so on.

Lastly, retrograde required reversing the array of pitches to play. For example, if the original melody contains [0, 3, 6, 5], the retrograde function would simply reverse the array to output [5, 6, 3, 0].

On the surface, despite being familiar with pitch and music theory in general, the assignment scared me in the fact that I thought there would be a lot to implement. I fully expected to have massive long sessions of struggle with this portion, but the logic seemed a lot more fluid than I expected. Not only that, with every pitch being so related and intertwined with one another through transposition, inversion, and retrograde, I was fully expecting a melody that is somewhat comprehensible; however, from my own personal opinion, the melody does not seem intertwined with one another at all.

If I were to extend this project, I think it would be nice to implement a way to generate rhythms that are structured. I believe rhythm to be a crucial part of creating a comprehensive melody, especially when it comes to flow. I think a major obstacle is determining the set of rules for the script to follow. Unlike pitch where there are implementations of transposition and inverse, there are so many combinations of rhythm that should have rules of when to be used.
